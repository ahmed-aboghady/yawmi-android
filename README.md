# يومي | YAWMI — النسخة المبسطة

تطبيق Android عربي لإدارة **خطة الأسبوع + مهام اليوم** بدون حساب أو إنترنت.

## فكرة التطبيق
- **خطة الأسبوع:** تكتب أهداف الأسبوع (مثلاً يوم الجمعة). تبقى ظاهرة طوال الأسبوع وتقدر تعلم المنجز منها.
- **مهام اليوم:** كل يوم تضيف قائمة مستقلة لليوم الحالي وتحدد ما أنجزته بعلامة صح.
- يبدأ الأسبوع يوم الجمعة، وتُربط أهداف الأسبوع تلقائياً بالأسبوع الصحيح.
- **Widget كبيرة قابلة لتغيير الحجم:** تعرض مهام اليوم وحالة الإنجاز، مع ملخص خطة الأسبوع. الضغط على المهمة في الويدجت يغيّر حالتها.
- حفظ محلي على الهاتف باستخدام Room. لا يوجد تسجيل دخول أو اشتراك أو إعلانات.

## بناء APK
1. افتح مجلد المشروع `YAWMI` في Android Studio حديث.
2. ثبّت JDK 17 و Android SDK Platform 36 عند الطلب.
3. انتظر Gradle Sync.
4. اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
5. ستجد APK في `app/build/outputs/apk/debug/`.
6. أضف Widget باسم **يومي** من قائمة Widgets في شاشة الهاتف الرئيسية، ثم كبّرها لتأخذ مساحة مناسبة.

## ملاحظات
- هذا مشروع مصدر Android Studio؛ لا أصفه بأنه APK مختبر قبل نجاح التجميع والتشغيل على جهاز Android.
- يفضل اختبار الـWidget على Launcher الهاتف المستهدف؛ بعض واجهات الشركات تختلف في طريقة عرض أحجام الويدجت.
